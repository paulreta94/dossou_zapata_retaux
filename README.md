# dossou_zapata_retaux

Auteurs : Paul-Etienne Rétaux, Samson Zapata-Tome et Gérard Dossou

Ce dossier contient le code de navigation inertielle et hybridée créé dans le cadre du projet "challenge navigation" de novembre - décembre 2024.

Conformément à ce qui a été présenté en cours, le dossier comprend deux algorithmes :
- une navigation hybridée reposant sur une navigation inertielle classique (fichiers MAIN_calcul_nav.py, MAIN_trace_nav.py et Entretien_localisation.py)
Pour désactiver l'hybridation, il suffit de commenter les lignes 133 à 140
- une navigation hybridée reposant sur une navigation inertielle simplifiée (fichier NavTEST.py)
Pour désactiver l'hybridation, il suffit de commenter les lignes 130 à 143 et de décommenter les lignes 144 et 145
